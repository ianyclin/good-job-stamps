# 好棒印章

給有三個孩子的家長用的集章簿：孩子做到一件**具體的好事**，就在月曆上蓋一個「你好棒！⭐」。
加到 iPhone 主畫面之後就像一個 app，沒有帳號、沒有伺服器，資料只存在你的手機裡。

## 功能

- **每個孩子各一頁（預設兩位，1–5 個可新增移除；移除要三次確認）**，點頭像切換，整頁換色一眼就知道是誰的；新增的孩子會自動拿到還沒人用的顏色主題。設定頁分成「孩子／原因／備份／其他」四個次分頁。預設是大寶海洋藍 🦁／二寶莓果粉 🐰／三寶葡萄紫 🦄，設定頁有 **11 種顏色**可挑（海洋藍、莓果粉、葡萄紫、太陽橘、森林綠、蜜桃粉、夢幻桃、薰衣草、湖水青、檸檬黃、石墨藍），名字能改，頭像可以選 16 種貼圖**或用孩子的照片**（自動裁方縮小，只存在手機與備份裡）。選到別人正在用的顏色會自動互換，三個人永遠不同色。
- **累計總數**：大數字是「現在有幾顆」（蓋章減掉扣除），下面一行是**跨越所有月份的累計**——「一共蓋過 137 顆 ・ 扣過 5 顆 ・ 從 5/1 起第 115 天」。
- **月曆集章卡**：左右箭頭或左右滑動換月；點任一天可以補蓋、看這天的紀錄、補寫原因、刪除誤蓋。
- **「今天好棒！」大按鈕**：按下去立刻蓋在今天，印章落下、星星噴出、「你好棒！」——動畫結束後才問你要不要加原因（可以不填、可以撤銷）。
- **滿 10 顆**：緞帶橫幅＋紙花；**滿 100 顆**：全螢幕煙火，孩子自己按「收下 ⭐」才結束，那一天的格子從此帶金框。
- **扣除**：要按住 1 秒才成立，沒有紅色、沒有警示音、星星不會被擦掉（另外用灰色「−1」標示），扣完可以復原。
- **兌換與總好棒**：「−」面板裡有「🎁 用好棒換東西」——寫品項與顆數就從「總好棒」（蓋章 − 扣除 ＋ 調整 − 已兌換）扣掉，兌換紀錄可看可刪。**換掉的只是可用數**：月曆星星、大數字、滿 10/100 慶祝都不受影響。以前累積的好棒可以在設定頁一次「調整」加進來（跨過的每滿 10 不補放慶祝）。
- **給家長的小語**：畫面最下方一句，點一下換一句（含「多找出明確可以蓋好棒的事實給孩子正向回饋喔」）。
- **紀錄頁**：點總數打開，逐筆看「什麼時候、因為什麼」，可以補寫原因或刪掉記錯的。
- **自訂常用原因（每個孩子分開）**：設定頁可以替每個孩子各自加原因（照你家的說法），內建的不合用就收起來；拖「≡」能調整順序，蓋章面板就照這個順序出（也可以改成「最近用過的自動排前面」）。新增時勾「每個孩子都加」就一次加給全家。手打過的原因預設會自動變成選項，不喜歡可以關掉（關掉後，手打的蓋章原因只會在「最近用過」出現一陣子；手打的扣除原因不會留下）。蓋章與扣除的清單分開管理。
- **蓋完章的面板**：「其他…」固定在第一顆（自己家的說法最精準）；原因太多時按右邊的「⌄」展開成多行，偏好會記住。「還有誰也做了？」按一下立刻幫那個孩子蓋（長按連蓋 N 顆時，他也記同樣的 N 顆）、再按一次整批悄悄收回。左下角「先跳過／完成」、右下角「蓋錯了，拿掉這顆」。
- **長按連蓋**：按住大按鈕不放，可以一次蓋 2–20 顆（一件事做很大、或一次補記）；原因選一次套整批，撤銷也是整批一起。
- **自動備份**：每次改動幾秒後，app 會自動把整份資料另存一份快照到手機裡，保留**最近 20 份與每天最後一份（60 天）**。設定頁看得到列表（時間、三個孩子當時各幾顆），誤刪誤扣都能一鍵還原。
- **雲端自動備份（GitHub）**：設定頁貼一次 GitHub 金鑰（教學就在設定頁裡，只勾 gist 權限），之後每次蓋章 15 秒後與切到背景時，自動把整份備份傳到你自己帳號的**私人 Gist**（只有你的帳號看得到）。換手機時貼同一把金鑰，一鍵整份拿回來。金鑰只存在手機上，不會進備份檔。為什麼不是 iCloud：Apple 不開放網頁 app 寫入 iCloud，這是 iPhone 上唯一能全自動的做法。
- **匯出備份**：設定頁「複製備份文字」或「傳出備份檔」（走 iPhone 分享表，可存到「檔案」、AirDrop 或傳給自己）；換手機時貼回去或選檔還原。超過 14 天沒匯出（而且雲端也沒在同步），齒輪旁會出現小灰點提醒。
- 音效用 WebAudio 合成（可關）；支援離線；尊重系統的「減少動態效果」設定。

## 檔案

```
index.html     整個 app（HTML + CSS + JS 都在這一個檔案裡）
manual.html    使用說明書（給家長與阿公阿嬤，可印出來貼冰箱；設定頁裡有連結）
manifest.json  加到主畫面用的名稱、圖示、顏色
sw.js          離線與安裝能力（Service Worker）
icons/         主畫面圖示
```

## 上傳到 GitHub 並開成網頁（GitHub Pages）

### 做法 A：放進現有的 `life-journal` 倉庫（最省事）

這個資料夾已經放在 `life-journal` 倉庫裡的 `stamps/`，所以只要：

1. 在電腦上打開終端機，進到倉庫資料夾，把新資料夾加進去並推上去：
   ```bash
   git add stamps
   git commit -m "新增好棒印章"
   git push
   ```
2. 等 1–2 分鐘，網址就是 **https://ianyclin.github.io/life-journal/stamps/**（結尾的斜線要留著）。
   （`life-journal` 的 GitHub Pages 已經開著，不用再設定。）

### 做法 B：開一個新的倉庫

1. 到 github.com → 右上角「+」→ **New repository**，名稱例如 `good-job-stamps`，選 Public，按 Create。
2. 在新倉庫頁面點 **uploading an existing file**，把 `index.html`、`manifest.json`、`sw.js` 和整個 `icons` 資料夾拖進去，按 **Commit changes**。
   （如果用終端機：`git init` → `git add .` → `git commit -m "好棒印章"` → 照 GitHub 給的指令 `git remote add origin …` → `git push -u origin main`。）
3. 倉庫的 **Settings → Pages → Build and deployment → Source** 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
4. 等 1–2 分鐘，網址會是 `https://<你的帳號>.github.io/good-job-stamps/`。

> 之後改了檔案再 push 一次就會更新。因為有離線快取，手機上要**重新開啟兩次**才看得到新版（第一次開會跳「有新版本」，點「更新」也可以）。

## 裝到 iPhone 主畫面

1. 用 **Safari** 打開上面的網址（Chrome 不行，iOS 只有 Safari 能加到主畫面）。
2. 點下方的 **分享** 按鈕（方框加向上箭頭）。
3. 往下找 **加入主畫面** → 右上角 **新增**。

之後從主畫面的圖示打開，會全螢幕、沒有網址列，沒網路也能用。

> **重要：** Safari 分頁和主畫面 app 的資料是分開存的。先加到主畫面、再從主畫面打開開始蓋章，才不會蓋了一堆之後「不見」。
> 如果已經在 Safari 裡蓋過，到設定頁「複製備份文字」，再到主畫面 app 的設定頁「貼上還原」就能搬過去。
>
> 另外：只放在 Safari 分頁裡用的話，一個禮拜沒開，iPhone 可能會自動把資料清掉（這是 Safari 的隱私機制）；裝到主畫面才會長期保留。**把主畫面上的圖示刪掉，紀錄也會一起消失**，換手機前記得先備份。

## 資料

- 全部存在這支手機的瀏覽器 localStorage（自動快照放在同一支手機的 IndexedDB）。**除非你自己開啟 GitHub 雲端備份**（傳到你自己帳號的私人 Gist），否則不會上傳到任何地方，程式也沒有其他對外連線。
- 所以「自動備份」救得了誤刪、誤扣、資料毀損，**救不了手機掉了或 app 被刪掉**——那種情況只有匯出過的備份檔救得回來。
- 換手機、清除網站資料、刪掉主畫面圖示，都會讓這支手機上的資料消失。超過 14 天沒匯出備份（而且雲端也沒在同步）時，齒輪圖示旁會出現一個小灰點提醒。
- 備份檔是純文字 JSON，可以貼到備忘錄、傳給另一半，或存到 iCloud。
- 萬一資料讀不出來（檔案毀損），程式會把原始內容另存一份而不是直接清空，並提醒你先備份。

## 本機預覽

Service Worker 不能在 `file://` 下運作，所以要用一個本機伺服器：

```bash
python3 -m http.server 8767 --directory stamps
```

然後開 <http://localhost:8767>，用瀏覽器的開發者工具切成手機尺寸看。
